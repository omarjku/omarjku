# motion

The animated GIFs on my profile and in my project READMEs are generated by code. No screen recordings, no AI video tools: every frame is a pure function of time, drawn on a `<canvas>`.

```
scenes/<name>.js   draw(ctx, t) for one video, plus an optional `music` score
engine/lib.js      easing, timelines, seeded randomness, text and shape helpers
engine/film.js     trailer kit: beat clock, camera, shot sequencer with transitions, slams, light, phone mockups
engine/stage.html  loads a scene onto a canvas (open it in a browser to preview live)
audio/synth.py     procedural soundtrack: synths, drums, risers and impacts arranged from the scene's score
render.mjs         headless Chromium draws each frame → ffmpeg → MP4 (with sound) + GIF / WebP
render-all.sh      renders every scene with the sizes used in the READMEs
```

## Render

Needs Node 18+, `ffmpeg`, Playwright with Chromium, and optionally `gifsicle` (smaller GIFs). Soundtracks need Python 3 with NumPy and SciPy (`MOTION_PYTHON` picks the interpreter).

```bash
node motion/render.mjs leyrd --scale 1.5 --gif 1000 --card 440   # → motion/out/leyrd.{mp4,gif} + leyrd-card.gif
node motion/render.mjs leyrd --still 2.5,7                        # single PNG frames, for checking a moment
motion/render-all.sh                                              # everything

# a trailer: 1080p60 with motion blur (2 sub-frames per frame), soundtrack, and a silent WebP loop for the README
node motion/render.mjs secondlook --scale 1.5 --fps 60 --shutter 2 --video --webp 960
```

Trailers are cut to a tempo: `film.js`'s `clock(bpm)` turns bars and beats into seconds, the shot list cuts on bar lines, and the same score drives `synth.py`, so every whoosh, impact and bell lands on the frame that needs it. The music is synthesised from oscillators and noise in NumPy; no samples or generative audio.

Frames render in parallel across CPU cores. Because `draw` depends only on `t`, any frame can be rendered on any worker in any order, and every scene ends where it began, so the GIF loops without a seam.

## GIF size

GIFs only store the pixels that change between frames, so the scenes keep backgrounds still and move the subject (the banner's mesh holds still while signals travel along it). That keeps each README GIF around 1–2 MB.

Fonts in `engine/fonts/` are from Google Fonts under the SIL Open Font License: Inter, JetBrains Mono, Instrument Serif, Space Grotesk, Hind Siliguri, IBM Plex Sans and IBM Plex Serif. The phone screenshots in `assets/secondlook/` are captures of the Second Look app running on its mock data. If Inter and Inter Display are installed locally they are used first.
